# Customer Segmentation Analysis

This project uses K-Means clustering to segment customers based on their annual income and spending score.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Elbow Method
5. K-Means Clustering
6. Visualization

## Output
Customer groups are identified into 5 segments for business analysis.
